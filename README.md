# Alpha Wear Sales Analysis & Interactive Dashboard

## Project Overview

This project analyzes Alpha Wear ecommerce sales data using Microsoft Excel.

The project covers data cleaning, sales analysis, revenue analysis, return/cancellation analysis, KPI development, and interactive dashboard creation.

## Tools Used

- Microsoft Excel
- PivotTables
- Power Query
- Excel formulas
- Data visualization
- Interactive slicers

## Data Preparation

The raw dataset contained data-quality issues, including missing and inconsistent values in the Quantity field.

The data was cleaned and prepared before analysis to improve the reliability of the results.

## Analysis Performed

The analysis focused on:

- Revenue by category
- Monthly revenue trends
- Sales channel performance
- Average Order Value (AOV)
- Return/cancellation rates
- Total revenue
- Total orders
- Total quantity

## Key Results

- Total Revenue: 486,813.14
- Total Orders: 2,999
- Average Order Value: 162.33

Sales performance was also compared across categories, sales channels, and months.

Return and cancellation rates were analyzed by product category to identify differences across the dataset.

## Interactive Dashboard

The final dashboard brings the analysis together into a single interactive view.

It includes:

- Total Revenue
- Total Orders
- Total Quantity
- Average Order Value
- Revenue by Category
- Monthly Revenue Trend
- Revenue by Sales Channel
- Return Rate by Category

The dashboard also includes interactive slicers for:

- Category
- Sales Channel
